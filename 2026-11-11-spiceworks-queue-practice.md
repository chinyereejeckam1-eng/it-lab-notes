spicework-queue session
Goal: Work a practice queue in my own Spiceworks Cloud Help Desk-- triage clarifying questions, diagnosis, and document resolutions, ticket by ticket.

What I did: Entered each ticket the way a user would (unassigned, default priority, no category) then assigned it to myself, set priority and category, posted clarifying questions before diagnosing, and closed with a root cause and prevention note.
Label printer shows ready, nothing prints (Marcus, warehouse lead, packing station): Set priority to medium-high (work slowed, not stopped) Category: Hardware / Printing. The first label job from the morning was sitting in the queue with an Error status, blocking every job behind it. Fix order mattered: check the print queue before touching the hardware --> cancel the errored job --> test print --> confirm all 5 labels print.

What I got wrong: My first instinct was to go look at the printer itself. The printer showed no error, and the problem was in the queue, not the hardware. Checking the queue first would have gotten there faster.

What I learned: A printer showing ready can still be blocked by one bad job in the queue. Check the queue before touching the hardware.
