spicework-queue session

Goal: Work a practice queue in my own Spiceworks Cloud Help Desk-- triage clarifying questions, diagnosis, and document resolutions, ticket by ticket.

What I did: Entered each ticket the way a user would (unassigned, default priority, no category) then assigned it to myself, set priority and category, posted clarifying questions before diagnosing, and closed with a root cause and prevention note.
Internet down (Priya, front office): Set priority to medium (single user) Category: Network. Her laptop was connected to Wi-Fi but on the guest network, not the office one, sitting behind a sign-in page. Fix order mattered: check which network the machine is actually on --> reconnect to the office SSID --> forget the guest network so it doesn't win again --> verify her sites load --> close with the prevention note (forget the guest network so the laptop stops roaming onto it).

What I got wrong: At first I mixed up what goes in the new ticket and what gets logged as I troubleshoot. Part A only goes in the ticket, the rest comes out through troubleshooting and goes in as notes and the resolution.

What I learned: A laptop can look connected and still be stuck behind a guest sign-in page. Check which network it's actually on before assuming the internet is down.
